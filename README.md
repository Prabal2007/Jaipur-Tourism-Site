# Jaipur Tourism Website 🌸

A responsive and interactive tourism website for Jaipur, built as part of the **Web Development Applications (WDA)** course project.  
The website highlights Jaipur’s attractions, shopping spots, cuisine, and tourism packages with a consistent cultural theme inspired by Rajasthani mandala art.

---

## 📌 Project Overview

The Jaipur Tourism Website aims to provide users with a single platform to explore:
- Popular tourist attractions
- Famous shopping markets
- Traditional Rajasthani food and restaurants
- Custom and predefined tourism packages

The project focuses on **clean UI design**, **structured content**, and **basic interactivity** using modern web technologies.

---

## 🛠️ Technologies Used

- **HTML5** – Structure of web pages  
- **CSS3** – Styling, layout, animations, and theme design  
- **JavaScript (Vanilla JS)** – Interactivity and DOM manipulation  
- **React (via CDN)** – Login and profile functionality  
- **Bootstrap** – Carousel and responsive components  

---

## ✨ Key Features

- Responsive **navigation bar** with hamburger menu
- **Hero carousel** showcasing Jaipur visuals
- **Live Weather API** on home page
- Mandala-inspired **color scheme and background elements**
- Cards for attractions, shopping, and cuisine
- **React-based Login/Profile system**
- Interactive map integration
- Separate pages for:
  - Attractions
  - Shopping
  - Cuisine
  - Tourism Packages
